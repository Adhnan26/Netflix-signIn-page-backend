🔐 Netflix Login Backend – Express API (Week 11 Project) ⚙️🛠️

This backend application was built to support my Netflix Login Clone frontend as part of my Week-11 learning project. It validates login credentials by checking predefined users and returns a boolean response to the frontend.

This was my first backend implementation, and it helped me learn how APIs work, how requests and responses flow, and how frontend and backend communicate together.

Built during my learning journey at Error Makes Clever (EMC), guided by Agnel John (Founder & Instructor) and supported by Nandhini (Co-Mentor).

✨ Backend Features :

✅ POST /login endpoint
✅ Validates predefined user credentials
✅ Sends response as true or false
✅ CORS enabled for smooth frontend communication
✅ Lightweight and beginner-friendly structure
✅ Deployed live using Render

🧠 What I Learned :

~ This backend project taught me: ~

How to create an Express server

How to handle POST requests

🧩 Tech Stack :

🟦 Node.js
🚀 Express.js
🔓 CORS
☁ Render Deployment                                                                                    

📌 API Endpoint :

POST → /login

Request Format:
{
  "email": "example@gmail.com",
  "password": "123"
}

Response:
true   → Valid user  
false  → Invalid credentials
